# Option proposal and slides

Obtain an objective, audience, two to five real options with cost, impact, risk, benefits and concerns, plus explicit weights for impact, risk and cost. Reject duplicate option names and a zero-weight comparison. Rank by the normalized visible score, with lower cost breaking ties. Show the ranking and every source input; do not hide the tradeoff behind a recommendation.

Create an editable PowerPoint for the decision meeting and a Word brief. Both are drafts; a manager still approves the recommendation before any spend or external message. If inputs are missing, ask the user instead of inventing options.

Run `python skills/proposal-package/scripts/run.py --input skills/proposal-package/references/example.json` from the project root. The example is not evidence about a real company.
