# Customer follow-up register

Capture the customer's actual request, responsible colleague, current evidence-backed status, next action, due date and source reference. Do not mark a call, email or booking complete merely because a record exists. The saved record is searchable in Activity and editable in the register.

If no owner or due date is known, ask. If a customer reply is blocked, set `needs_attention`, explain the blocker and route it to the manager. For real contact, use an approved Gmail action to the demo inbox; keep the follow-up status aligned with the provider receipt.

Run `python skills/customer-followup/scripts/run.py --input skills/customer-followup/references/example.json` from the project root; example names are fictional.
