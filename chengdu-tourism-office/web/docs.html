Company Workspace API

Open workspace ↗

One execution path for your GUI, scripts and MCP clients. Run local skills, edit the organization, manage files and review external actions. The server binds to localhost and uses this computer’s single workspace.

Download OpenAPI 3.1 specification

Quick start
curl http://127.0.0.1:8765/api/skills
curl -X POST http://127.0.0.1:8765/api/skills/team-capacity/run \
  -H "Content-Type: application/json" -d '{"inputs":{}}'

For remote writes, a successful request creates awaiting_approval. Inspect the saved run, then approve it in Activity or explicitly call its approval endpoint. Use a unique idempotency_key when retrying a submission. The explorer below operates on your real local workspace.
