# Recorded execution evidence

`launch-execution.json` contains the prompt, final agent snapshot, actual runtime results, company records and file registry from the narrated recording. One request produced 20 completed skill executions across 16 distinct skills, 7 delegated fictional colleagues and 10 files. There were no failed or pending runs and no manual skill submissions.

`generated-files/` contains ten actual downloaded outputs: proposal slides, decision brief, project workbook, responsibility matrix, campaign brief, launch checklist, budget workbook, finance forecast, management handoff and final PDF report.

`agent-timeline.json` preserves measured snapshots from the live recording. The completed run used 24 model requests and 26 function-tool calls over 303.8 seconds. Provider-reported usage summed to 800,795 tokens across requests, including repeated context; this is not a unique-context size or cost estimate. The final video compresses waiting periods to 3:01 and adds narration.

Business outcomes and completion evidence are explicitly simulated. Real skill execution and local artifact creation do not establish independent supplier verification, a real product release, payment or external delivery. Colleague profiles represent delegation within one model-driven orchestrator.

All people and business facts used in this recording are fictional. No credentials, personal runtime databases or private source files are included here.
